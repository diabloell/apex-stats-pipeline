# Apex Stats Pipeline — экспорт в Photoshop

Теперь Python **не рисует PNG**. Он читает результаты скримов, считает очки и MVP и готовит два JSON-файла. Скрипт `photoshop/fill_from_json.jsx` открывает **оригинальный PSD**, заменяет текст в существующих слоях, переключает нужные слои легенд, при наличии фотографии заменяет смарт-объект и сохраняет редактируемый PSD + PNG.

## Папки и файлы

```text
apex-stats-pipeline/
├── main.py
├── stats.py
├── export_photoshop.py
├── player_names.py
├── data/
│   └── scores.json
├── templates/
│   ├── match_mvp.psd        ← оригинал «Матч статы_2(2).psd», переименовать копию
│   └── table.psd            ← оригинал «ТАБЛИЦА НА 20 КОМАНД_16 НА 9_голубой.psd», переименовать копию
├── assets/
│   └── players/
│       └── DIGVIBEZZ.png   ← пример заранее отформатированной фотографии MVP
├── photoshop/
│   └── fill_from_json.jsx
└── output/
    └── photoshop/         ← JSON, итоговые PSD и PNG
```

## Как запустить

1. Скопируй новые `.py`, создай `photoshop/`, положи туда JSX. Оригинальные PSD положи в `templates/` **под именами выше**. Используй **копии** PSD: оригиналы не меняем. Если Photoshop у друга на другом компьютере, ему понадобится такая же папка проекта с `templates/`, `assets/players/`, `photoshop/` и экспортированными JSON. Пути в JSON относительные и не зависят от диска.
2. Проверь, что старый `data/scores.json` на месте. Pillow и локальные файлы шрифтов для этого пайплайна не нужны; **но шрифты должны быть установлены в Photoshop на компьютере друга**.
3. Запусти `python main.py` в PyCharm. Для другого матча можно указать `python main.py --match 2` (по умолчанию матч 5). Для заголовка — `--event "ALGS CHAMPIONSHIP 2025"`.
4. Скрипт создаст `output/photoshop/table.json` и `output/photoshop/mvp_match_5.json`.
5. В Photoshop на компьютере друга: **File → Scripts → Browse… →** `photoshop/fill_from_json.jsx`, затем выбери **один** нужный JSON.
6. Проверь результат в `output/photoshop/`: готовые `.psd` со слоями и `.png` для Telegram. Для второго JSON снова запусти JSX.

## Какие слои меняются

- **MVP:** заголовки, текст в каждой из трёх групп `Статы N игрока`, изображения легенд в готовой группе `Персонажи` и смарт-объект `Фото (два клика)`.
- **Таблица:** существующие текстовые слои команд, киллов и очков внутри групп `1`–`20`, а также текстовый заголовок. Расчёты не изменены.
- **Логотипы команд:** старые логотипы Falcons скрываются, а **новые друг вставляет и подгоняет вручную**, как и раньше.
- **Фотографии:** имя файла фото должно совпадать с **официальным** ником MVP, например `assets/players/DIGVIBEZZ.png`. Без фото JSON всё равно создаётся для тестов, но вывод считается **черновиком** — скрипт скроет чужую фотографию. Этот MVP-шаблон публикуется только для игроков с заранее подготовленными фото из нужного списка СНГ.
- **Новые легенды:** для `axle` в присланном PSD не обнаружен оформленный слой, так что скрипт выдаст предупреждение и не будет показывать вместо него другую легенду.

## Важно

- В этом пакете **нет** самих PSD, шрифтов, фотографий и турнирного JSON — у тебя они уже есть. Не добавляй чужие PSD/фото/шрифты в публичный репозиторий без разрешения. В существующий `.gitignore` добавь `assets/players/` и убедись, что уже есть `assets/fonts/`, `templates/*.psd` и `output/`.
- Старые `render_table.py` и `render_match_mvp.py` больше **не используются**, после контрольного коммита их можно убрать из проекта.
- Синтаксис Python и JSON проверен на тестовом JSON турнира. **JSX невозможно выполнить без настоящего Photoshop**, поэтому первый запуск обязательно проверь на компьютере друга, прежде чем полагаться на результат. Если есть ошибка JSX, пришли точный текст — исправим.
- Исходные PSD скрипт открывает как шаблоны и закрывает **без сохранения изменений**. Итоговые PSD/PNG сохраняются в `output/photoshop/`.
